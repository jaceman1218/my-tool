# my-tool

シンプルなランディングページを持つツールのサンプルプロジェクトです。
Git / GitHub の操作フロー（Feature Branch → コミット → PR → マージ）を学ぶための練習用リポジトリとして作成しました。

## 概要

- トップページ（`index.html`）はダークテーマのシンプルなランディングページです
- 機能紹介セクション、CTA ボタンなどの基本的な構成を含みます

## 技術スタック

- HTML / CSS（フレームワークなし、素の実装）

## セットアップ

特別なビルド手順は不要です。`index.html` をブラウザで開くだけで表示されます。

```
# ローカルで開く場合
start index.html
```

## 開発フロー

このプロジェクトは Feature Branch ワークフローで開発しています。

1. `main` から `feature/xxx` ブランチを作成
2. 機能を実装してコミット
3. Pull Request を作成
4. レビュー後、`main` にマージ
